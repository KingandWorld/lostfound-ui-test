## 一、设计目标

1. 对**核心用户流程**建立端到端自动化（登录/发布/搜索/注册/认领），从用户视角守护发布质量；
2. 采用 **Page Object 模式**，页面元素与用例逻辑解耦，降低维护成本；
3. 建立**失败现场采集机制**（截图/页面源码/网络日志/控制台），让 CI/本地失败可一键定位。

## 二、技术栈与结构

| 项 | 选型 |
|----|------|
| 语言/框架 | Python + pytest |
| 自动化引擎 | Playwright（sync API，Chromium） |
| 模式 | Page Object（7 个页面类） |
| 报告 | allure-pytest（含失败附件自动挂载） |
| 重试 | pytest-rerunfailures（超时/网络重试，断言不重试） |
| 运行入口 | 本地一键脚本（Windows bat / Linux sh 双平台） |

```
lostfound-ui-test/
├── pages/                  # Page Object 页面类（7 个）
│   ├── base_page.py        # 基类：导航/点击/填充/等待/截图 + 校验提示轮询
│   ├── login_page.py / home_page.py / lost_list_page.py
│   ├── publish_page.py / register_page.py / item_detail_page.py
├── testcases/              # 21 条用例（5 个模块）
├── conftest.py             # fixture：browser/page + 失败现场四件套 hook
├── run_ui_tests.bat/.sh    # 一键运行：测试 → Allure → history 趋势 → 打开
└── Jenkinsfile             # 声明式流水线（服务器手动触发/夜间报告入口）
```

## 三、用例设计（21 条）

| 模块 | 用例数 | 覆盖点 |
|:----:|:---:|--------|
| 登录 | 5 | 成功/邮箱登录/错误密码/空表单校验/注册跳转 |
| 发布 | 4 | 完整发布/必填校验/未登录保护/分类下拉 |
| 搜索 | 2 | 已知关键词有结果/不存在关键词空结果 |
| 注册 | 5 | 字段校验 4 + 成功 1（前端契约缺陷阻断，skip 留档） |
| 认领 | 5 | 弹窗结构/空说明校验/重复申请拒绝/自认领拦截/成功（认领池依赖，skip 留档） |

**设计要点：**

- **页面类粒度**：以用户视角划分（登录页/发布页/列表页/详情页），组合流程由用例编排；
- **断言分层**：UI 断言（提示文案/元素状态）+ 接口断言（`expect_response` 等待 `/api/*` 请求）——点击"搜索"后必须等待接口响应，避免 networkidle 误判；
- **稳定性处理**：路由重渲染等待（600ms）、校验提示异步轮询、`--proxy-server=direct://` 规避系统代理干扰；
- **与接口层呼应**：同一测试账号，协议层 + 表现层双重验证；错误密码用例沿用接口层契约（5 次锁定），放最后执行 + 宽断言。

## 四、失败现场四件套（质量工程）

每次用例失败自动采集并挂载到 Allure 报告：

| # | 采集项 | 用途 |
|:-:|--------|------|
| 1 | 页面截图（PNG） | 视觉现场 |
| 2 | 页面 HTML 快照 | 结构与元素状态 |
| 3 | 网络请求摘要 | 定位接口报错/超时 |
| 4 | 浏览器控制台日志 | 前端 JS 异常 |

> 失败现场四件套让"失败可定位"——本地一键运行或 CI 触发后，打开 Allure 报告即可看到完整现场，无需复现。

## 五、运行策略（资源约束下的方案C）

| 环境 | 策略 | 依据 |

## 七、卡点与解法（工程经验沉淀）

| 卡点 | 现象 | 解法 |
|------|------|------|
| 系统代理干扰 | 7890 代理未启动时 `--no-proxy-server` 无效 | `--proxy-server=direct://` 显式直连 |
| 路由重渲染 | 列表页输入标题后立即点搜索偶发失效 | 填充后等待 600ms 再点（内置页面类） |
| 异步校验提示 | `.el-form-item__error` 渲染有延迟 | 轮询等待封装进 BasePage |
| headless 进程名 | Chromium headless 进程为 `chrome-headless-shell.exe` | 按真实进程名排查/杀进程 |
| 依赖下载慢 | Playwright 内核下载慢 | `PLAYWRIGHT_DOWNLOAD_HOST` 国内镜像前缀 |
